# Pangasinan Heritage Mobile App

React Native + Expo Go mobile companion app for the Pangasinan Heritage Digital Showcase.

## Getting Started

```bash
cd mobile
npm install
npx expo start
```

Scan the QR code with the **Expo Go** app on your iOS or Android phone.

## Screens

| Tab | Description |
|-----|-------------|
| Explore | Hero banner, featured destinations, editorial spotlight |
| Destinations | Live search + category filter of all 8 places |
| Heritage | Cultural editorial stories |
| Saved | Offline bookmarked destinations |
| Detail | Full-screen destination page with highlights & visitor essentials |

## Tech Stack

- React Native 0.76
- Expo SDK 52
- Expo Router 4 (file-based navigation)
- Expo Image (optimized image loading)
- AsyncStorage (offline favorites)
- @expo/vector-icons (Ionicons)
